Manual test checklist
  • Type on a real phone: does autocapitalize kick in at sentence starts?
  • Type "hi there.." then a real double-space — does it become a period? (OS-level, not guaranteed)
  • Misspell a word — does the native red squiggly spellcheck underline appear?
  • Select text, click Bold/Italic — does it wrap with ** / * correctly?
  • Click H / List / Check on an empty line and a non-empty line
  • Click "Insert fake image attachment" mid-document — lands at cursor, not at the end
  • Compare the live markdown source panel against what you typed — no corruption
  • Undo/Redo buttons work as expected

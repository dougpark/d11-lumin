# dark color scheme ideas

## Tech

| Element | Color Role | Hex Code | Description/Feeling |
| :--- | :--- | :--- | :--- |
| **Primary Background** | Main Blog Area | `#121212` | Deep, non-black charcoal. Low strain, professional. |
| **Secondary Background** | Cards, Widgets, Separators | `#1E1E1E` | Slightly lighter than the main background, adding depth. |
| **Text Color** | Body Text, Headings | `#DCDCDC` | Soft off-white. Easier on the eyes than pure white. |
| **Primary Accent** | Links, Buttons, Highlights | `#0096FF` | **Electric/Cyan Blue.** Clean, digital, and high-energy. |
| **Secondary Accent** | Subheadings, Icons | `#00BCD4` | A softer cyan/teal to support the primary accent. |

## Art

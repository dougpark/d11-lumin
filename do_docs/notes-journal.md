# Journal Mode

## new note list features
- sort a note list by create-date, and show the create-date in the note list.  this is useful for a journal mode, where you want to see your notes in chronological order.  it should be a in a new 3 vertical dots menu on the note list, and it should be a toggle between sort by journal view and standard view.


## note ui
- have a edit create-date feature to set the position of an existing note in the journal list.
- add edit date entry in the 3 vertical dots menu on the note.
- edit an existing note should not change the create-date, but it should update the update-date.  this is useful for a journal mode, where you want to see your notes in chronological order, but you also want to see when you last updated a note.
